# AI Debugging Sessions

## Session 1: Project setup
- **Prompt:** How do I set up a React project with Vite and structure a multi-step form?
- **What I learned:** Component structure, lifting state up to a parent, conditional rendering with step state.

## Session 2: Validation
- **Prompt:** How do I validate email and password in real time with regex?
- **What I learned:** onChange validation, regex test(), disabling Next button until the step is valid.

## Session 3: Dev server terminal issue
- **Prompt:** I ran npm install in the same terminal where npm run dev was running. What do I do?
- **What I learned:** Use a separate terminal for commands while the dev server runs.

## Session 4: React Hook Form + Zod
- **Prompt:** How do I migrate a useState form to react-hook-form with a zod schema?
- **What I learned:** register(), zodResolver, mode: "onChange", sharing schema rules across steps.

## Session 5: Responsive design
- **Prompt:** My form is not responsive on all screen sizes. How do I fix it?
- **What I learned:** clamp() for fluid sizing, box-sizing, media queries, testing with Chrome device toolbar.
